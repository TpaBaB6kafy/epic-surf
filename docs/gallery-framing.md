# Редактор кадрирования главной страницы

Открыть: http://localhost:3000/ru?edit=1 (или http://localhost:3000/?edit=1).

Одна панель работает с фотографиями в галерее, трёх карточках мероприятий, четырёх шагах «Как проходят уроки» и всех пяти вариантах уроков. Можно сразу перейти к нужной секции: #gallery, #events, #how-it-works, #lessons.

1. Нажать на нужную фотографию. В панели появятся название секции и выбранного контейнера.
2. Изменить «Масштаб», «По горизонтали» и «По вертикали». Стрелки дают шаг в 2 пункта, «Сброс» возвращает начальную настройку выбранного кадра.
3. При масштабе 1× по одной оси может не быть свободного пространства для движения. Увеличение выше 1× создаёт запас по обеим осям. Масштабирование теперь привязано к положению кадра: исправлена ошибка, из-за которой увеличение не давало перемещать фото по ранее необрезанной оси.
4. Для другого варианта урока использовать обычные стрелки выбора урока, затем нажать на новое фото. У каждого варианта отдельная настройка.
5. Для мобильной композиции уменьшить окно до 699 px или включить мобильный режим в инструментах браузера. Настройки телефона и десктопа раздельные. В галерее также раздельны большая и малая рамки; обложка мероприятия не меняет тот же снимок в галерее.
6. «Copy config» или «Скачать JSON» экспортирует настройки всех секций вместе. Результат передать для сохранения в app/data/gallery-framing.json.

Черновик сохраняется в localStorage этого браузера под прежним ключом epic_gallery_framing_draft; существующие настройки не удаляются. Без ?edit=1 панель скрыта, но черновик продолжает отображаться. Для других устройств и посетителей нужен перенос JSON в проект. Черновик EN/RU общий. Полноэкранный просмотр показывает целое фото без редакторского кадрирования.

Рамка остаётся неподвижной, перемещается только изображение внутри неё. Диапазон ограничен доступными пикселями: некоторые фото блока шагов уже обрезаны при экспорте из дизайна, поэтому редактор не восстанавливает участки за пределами этих исходников.

## Прежний редактор досок

Image tuner для аренды по-прежнему доступен отдельно:
- http://localhost:3000/surfboard-rental-danang?edit=1
- http://localhost:3000/ru/surfboard-rental-danang?edit=1

Выбрать доску, затем Front / Back / Fins / Thumb. Параметры Scale / X / Y / Rotate, экспорт Copy config. Его черновик хранится отдельно: epic_rental_image_adjustments_draft.

## Проверки

12 сценариев браузера: галерея и просмотр, сенсорные жесты и трекпад, реальные смещения обеих осей при 1.1×/1.5×/2.5× для горизонтального и вертикального кадра, все 12 контейнеров других секций на 1440 и 390 px, раздельные настройки, повторная загрузка, экспорт и сброс. До исправления тест смещения воспроизводил нулевое движение; после исправления проверки прошли. Снимки секций: qa-output/gallery/framing-*.jpg.
