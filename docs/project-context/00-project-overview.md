# Project Overview

## What this project is

Epic Surf School Da Nang website built with Next.js App Router, React, Tailwind CSS v4, and client-side interactive sections.

## Main site goal

- Present Epic Surf School in Da Nang.
- Sell surf lessons and surfboard rentals.
- Route visitors to Alteg/YClients booking, WhatsApp, Telegram, Zalo, Google Maps, and social channels.
- Support partner referrals for hotels, villas, agencies, creators, retreats, and local businesses.

## Site languages

- English: `/`
- Russian: `/ru`

Partner pages:

- English: `/partners`
- Russian: `/ru/partners`

## Target audience

- Tourists and beginners looking for surf lessons at My Khe Beach.
- People who want surfboard rental in Da Nang.
- English-speaking and Russian-speaking visitors.
- Local business partners who can refer guests.

## Current domain and deploy

- Default canonical domain: `https://www.surfdanang.com`
- Domain config source: `app/data/siteConfig.js`
- Optional override: `NEXT_PUBLIC_SITE_URL` or `SITE_URL`
