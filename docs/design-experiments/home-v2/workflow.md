# Home V2 workflow

## Purpose

Home V2 is a hidden test version of the future Epic Surf School homepage. It lets the team review the new surf-zine / editorial poster-collage direction without changing the production homepages.

## Branch

- Active branch: `design/home-v2-poster-collage`.
- Keep Home V2 work in this branch until the experiment is approved.
- Do not merge this branch into `main` while `/home-v2` and `/ru/home-v2` are still test routes.
- Do not replace production routes `/` or `/ru` before approval.

## Local URLs

Run the local dev server:

```bash
npm run dev
```

Use these URLs for local review:

- `http://localhost:3000/home-v2`
- `http://localhost:3000/ru/home-v2`

The existing production homepages remain:

- `http://localhost:3000/`
- `http://localhost:3000/ru`

## Preview URLs

Vercel Preview for branch `design/home-v2-poster-collage` opens the deployment root `/` by default.

Important: the preview root currently shows the old homepage. To review Home V2, manually open the V2 paths on the preview domain:

- `https://{preview-domain}/home-v2`
- `https://{preview-domain}/ru/home-v2`

Use the exact preview domain generated by Vercel for the latest commit in this branch.

## Noindex and sitemap rules

- `/home-v2` and `/ru/home-v2` must be accessible by direct link for review.
- Both routes must remain `noindex, nofollow`.
- Keep route-level metadata in:
  - `app/(en)/home-v2/page.js`
  - `app/(ru)/ru/home-v2/page.js`
- Both route files must keep `robots.index = false`, `robots.follow = false`, and matching `googleBot` settings.
- Do not add `/home-v2` or `/ru/home-v2` to `app/sitemap.js`.
- Do not add Home V2 routes to public header/footer navigation or SEO link sets.

## Commit and push cycle

1. Make focused changes in the Home V2 branch.
2. Verify the affected local routes, especially `/home-v2` and `/ru/home-v2`.
3. For Home V2 routing, SEO, or UI changes, run the relevant checks when practical:

```bash
npm run lint
npx playwright test tests/home-v2.spec.js
```

4. Commit with a clear message that names the Home V2 area changed.
5. Push `design/home-v2-poster-collage`.
6. Open the Vercel Preview domain and manually check `/home-v2` and `/ru/home-v2`.
7. Confirm the preview root `/` still behaves as expected for the branch and remember it is not the Home V2 review URL.

## Final replacement plan

After Home V2 is approved:

1. Move the approved Home V2 experience onto `/` and `/ru`.
2. Preserve existing booking, rental, messenger, analytics, partner attribution, language switching, canonical, and structured data behavior.
3. Update canonical and language alternate metadata for the production homepages if route ownership changes.
4. Remove or retire the temporary `/home-v2` and `/ru/home-v2` routes, or keep them only if there is a documented post-launch reason.
5. If temporary routes remain after launch, keep them out of the sitemap and decide whether they should redirect to `/` and `/ru`.
6. Update `app/sitemap.js` only for approved production routes, never for abandoned experiment URLs.
7. Run production checks for `/`, `/ru`, sitemap, robots, analytics events, booking modal, rental modal, messenger links, and mobile layout.
8. Merge to `main` only after approval and verification.
